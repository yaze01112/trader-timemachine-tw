# trader-timemachine-tw（台股版時光機）

改編自 Jake Schincariol 的 day-trader-skill（MIT 授權）裡的 trader-timemachine，
只把市場設定改成台灣證券交易所：

- 時區：台北（UTC+8），沒有日光節約時間
- 交易時段：09:00 開盤，13:25 結束連續交易，每天 53 根 5 分鐘 K 棒
  （13:25–13:30 是收盤集合競價，Yahoo 不提供那根 K 棒，所以模擬到 13:25 為止）
- 股票代號：輸入 `2337` 會自動變成 `2337.TW`；上櫃股票請自己打 `6488.TWO`
- 沒有半日交易日

模擬方法和原版完全相同：每一根剩下的 K 棒，都從過去同一時段（前後 2 根）隨機抽一根，
依比例套到目前價格；同一根 K 棒同時碰到停利與停損時，算成先碰停損（保守）。

`${CLAUDE_SKILL_DIR}` 是這個技能所在的資料夾。

```bash
# 即時抓 Yahoo 資料（需要能連到 query2.finance.yahoo.com）
python3 "${CLAUDE_SKILL_DIR}/timemachine_tw.py" run --symbol 2337 --date 2026-10-20 \
    --entry 102 --stop 100.75 --target 103.25 --entry-time "9:30 AM"

# 用存好的資料檔（Yahoo chart JSON，.json 或 .json.gz）
python3 "${CLAUDE_SKILL_DIR}/timemachine_tw.py" run --offline 2337.TW-60d5m.json.gz --symbol 2337 \
    --date 2026-10-20 --entry 102 --stop 100.75 --target 103.25 --entry-time "9:30 AM" --now "2026-10-27 14:00"
```

其他參數：`--replays N`、`--seed N`（預設 19，同樣的種子會得到同樣的結果）、
`--until 13:00`（提早出場時間）、`--side sell`（放空）、`--json`、`--write`。
時間一律用台北時間。

## 使用步驟

1. 跟使用者確認：股票代號、日期、進場價與進場時間（必須是 5 分鐘 K 棒的收盤時間）、停損價、停利價。
2. 執行 `timemachine_tw.py run`。
3. 依序告訴使用者：先碰停利、先碰停損、都沒碰到的機率，收盤價的中位數與 90% 區間，平均 R，
   歷史回測那一行，最後是結論那一行，並說出使用的種子。
4. 結論是「接近擲銅板」就直說，不要美化。模擬和歷史回測結果不一致時也要講出來。
5. 一定要提醒一次：這是用過去 60 天資料做的模擬，不是預測。法說會、財報、重大新聞、
   漲跌停都可能出現過去 60 天沒發生過的走勢。台股有 10% 漲跌停，跌停鎖死時停損可能根本賣不掉，
   實際虧損會比 −1R 大。

## 規則

- 這個技能只做模擬，不下單，也不提供買賣建議。
- 資料少於 20 個完整交易日時會拒絕執行。
- 不要把模擬勝率說成未來勝率。
